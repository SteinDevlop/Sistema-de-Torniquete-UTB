# Carpeta Legacy
## Descripcion

Esta carpeta son archivos relacionados con el equipo anterior de este proyecto, el equipo decidio archivar en esta carpeta la informacion para futuro desarollo

# Estructura

```legacy/files```: Archivos de piezas para impresion

```legacy/trigger_cam```: Codigo arduino

```legacy```: Codigo python para activar camara y sus test

## Utilidad

- Su utilidad radica en la carpeta legacy/files, contiene modelos de impresion del torniquete.

- Sin utilidad para el desarollo integro del sistema backend o frontend
